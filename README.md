# TraceMap

Open-source tools for making regulatory compliance understandable to people who are
not compliance specialists.

## Tools

**[TraceMap catalog](TraceMap-catalog/)** generates a single, self-contained HTML
file that explains which regulations apply, what each requires in plain language, and
which documents address each requirement. It runs offline in any browser, with no
server or login. Data lives in YAML files, or in an Excel workbook that converts to and
from YAML. See the example built from `TraceMap-catalog/data-example/`, and the
[catalog README](TraceMap-catalog/README.md) to get started.
